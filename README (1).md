# Feira de Profissões — Empreendedorismo e Gestão Empresarial

Portfólio digital desenvolvido para a **Feira de Profissões**, apresentando a rotina, a evolução histórica e o panorama atual do mercado de trabalho na área de **Empreendedorismo e Gestão Empresarial**.

## Estrutura do Repositório

- `index.html`: Estrutura semântica em HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- `style.css`: Folha de estilos CSS3 com paleta executiva, layout responsivo (Grid e Flexbox) e gráfico de setores.
- `README.md`: Documentação do projeto.

## Como ativar o GitHub Pages

1. Crie um repositório público no GitHub e faça upload dos arquivos `index.html`, `style.css` e `README.md`.
2. Acesse **Settings** (Configurações) > **Pages**.
3. Em **Build and deployment**, selecione `Deploy from a branch`.
4. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
5. Aguarde cerca de 1 minuto e copie o link gerado para entregar no trabalho.
